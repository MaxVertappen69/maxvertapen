# Program Konversi Suhu (Go)

Aplikasi CLI sederhana berbasis bahasa pemrograman Go untuk mengonversi suhu Celsius ke Fahrenheit, Kelvin, dan Reamur disertai validasi input.

## Fitur
1. Konversi Celsius ke Fahrenheit
2. Konversi Celsius ke Kelvin
3. Konversi Celsius ke Reamur
4. Validasi input angka dan batas fisik suhu nol mutlak (-273.15 °C)

## Cara Menjalankan
```bash
go run main.go
```
